## What it does

`main.ts` (TypeScript, Node 22, no dependencies) deterministically writes
one job title to `/output/entry.txt` — nothing else, no trailing newline:

> **Senior Apologizer for Self-Driving Cars**

## Why this title

A real-sounding corporate title ("Senior … for …") with one specific,
funny twist: a person whose entire job is apologizing on behalf of
self-driving cars. It reads instantly, is easy to picture someone
actually doing, and the joke lands on the first read. 40 characters,
well under the 60-character cap.

## Run

```sh
node main.ts
cat /output/entry.txt
```
